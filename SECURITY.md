# Security Policy

## Supported Versions

We provide security updates for the latest major/minor releases of Enigma:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of Enigma seriously. If you believe you have found a security vulnerability in this project, please report it responsibly:

1. **Do NOT open a public GitHub issue** for sensitive security vulnerabilities.
2. Report the vulnerability via [GitHub Security Advisories](https://github.com/DNahar74/enigma/security/advisories/new) or by contacting the project maintainer directly.
3. Please include the following details:
   - Type of issue (e.g. credential exposure, injection, memory corruption)
   - Step-by-step instructions or proof-of-concept to reproduce the issue
   - Impact of the issue
   - Any suggested mitigations or patches

### Response Timeline

- **Initial acknowledgment**: within 48 hours.
- **Assessment & confirmation**: within 5 business days.
- **Fix & advisory release**: as quickly as feasible, coordinated with the reporter.

Thank you for helping keep Enigma and our users safe!
